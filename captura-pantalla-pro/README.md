# 📸 Captura Pro — Extensión para Google Chrome (Manifest V3)

Extensión para **Google Chrome** que permite realizar capturas de pantalla de cualquier página web en **3 modos** y guardarlas como **PDF** o como **Imagen (PNG / JPG)**:

1. **📜 Página Completa (Scroll Automático):** Recorre automáticamente toda la página desde el inicio hasta el final, oculta cabeceras flotantes repetidas (`fixed`/`sticky`) en los fragmentos intermedios y une todo en un único lienzo de alta resolución.
2. **✂️ Captura Parcial (Selección de Área):** Te permite arrastrar el ratón sobre la página para seleccionar el recorte exacto que necesitas, ajustar sus esquinas y guardarlo directamente como **PDF**, **Imagen PNG** o abrirlo en la **Vista Previa**.
3. **🖥️ Área Visible Actual:** Captura al instante exactamente lo que se muestra en la ventana actual del navegador.

---

## 🚀 Cómo instalarla en Google Chrome

1. Abre **Google Chrome** y escribe en la barra de direcciones:
   ```
   chrome://extensions/
   ```
2. En la esquina superior derecha, activa el interruptor **Modo de desarrollador** (*Developer mode*).
3. Haz clic en el botón **Cargar descomprimida** (*Load unpacked*) que aparece arriba a la izquierda.
4. Selecciona esta subcarpeta:
   ```
   c:\Users\csolo\Documents\browser-extensions\captura-pantalla-pro
   ```
5. ¡Listo! Fija el icono de **Captura Pro** (🧩 → 📌) en la barra superior de Chrome para tenerlo siempre a mano.

---

## 🛠️ Modos de Guardado y Exportación

Tanto desde el menú emergente como desde el estudio de **Vista Previa**, puedes exportar tus capturas en:

- **📄 Documento PDF:**
  - **PDF Página Continua (Sin cortes):** Genera un PDF de una sola página con las proporciones exactas de la captura completa, evitando cortes a mitad de texto o imágenes.
  - **PDF Paginado A4:** Divide automáticamente capturas largas en páginas estándar tamaño A4 listas para imprimir.
- **🖼️ Imagen PNG:** Máxima calidad sin pérdida de compresión.
- **📷 Imagen JPG:** Tamaño de archivo reducido y ligero.
- **📋 Copiar al portapapeles:** Copia la captura con un clic para pegarla directamente en documentos, correos o chats.

---

## ⌨️ Atajos de teclado rápidos

- **`Alt + Shift + F`**: Iniciar captura de **Página Completa**.
- **`Alt + Shift + S`**: Iniciar selector de **Captura Parcial**.
